# Four-PR Publishing Plan

**PR #1 — Research foundation:** primary issuer verification (KO vs COKE), SEC FY2025/FY2023 Form 10-Ks, analysis framework and ethical boundary.

**PR #2 — Historical statements:** public GAAP income and cash flow FY2021–2025, comparative BS FY2022–2025, OCI FY2021–2025, and automated reconciliation evidence.

**PR #3 — Accounting analysis:** margins, net-income-to-CFO indirect reconciliation, selected liquidity ratios, accrual timing observations and a formula-based 8–10-tab Excel workbook. One PR per independent milestone.

**PR #4 — Portfolio communication:** recruiter-oriented executive brief, 10-slide PowerPoint with notes, slide-by-slide professional English presentation transcript, release checklist and upload status.

**Binary files:** upload to `04-...release` branch if GitHub connector cannot send XLSX/PPTX binaries reliably. Never claim files exist in the repository until verified via GitHub directory reads.

**Privacy:** Keep the repository Private through development. Do not change visibility without explicit owner approval.

**User learning:** This work is a study aid and a potential internship portfolio; the owner should be able to reproduce significant source checks and explain findings independently. AI drafting assistance should not be misrepresented as unassisted work.
